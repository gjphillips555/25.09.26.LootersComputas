To print at true size: use Download 360×124 mm PDF and print that file at Actual size / 100% — never “Fit to page”. The PDF page is exactly the plate (360 × 124 mm) with 78 mm cap-height letters.

If you use the browser Print dialog instead, set paper to a custom 360 × 124 mm size (or A3 with the A3 PDF, which includes crop marks and a 100 mm calibration line). Turn on background graphics so bolt holes print. After printing, check with a ruler: the plate should be 360 × 124 mm and the letters 78 mm tall.

A4 paper is only 297 mm wide, so a 360 mm plate cannot print at 100% on A4.
